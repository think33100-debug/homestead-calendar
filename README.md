# homestead-calendar

홈스테드 스테이 실입실(VENDIT) 현황 — **화면(프론트엔드)만** 있는 저장소.

- 데이터 수집·저장은 Google Apps Script 백엔드에서 처리 (이 저장소에 없음)
- 예약 데이터, 접근키, iCal 링크는 이 저장소에 **포함되지 않음**
- 연결 정보(API 주소·접근키)는 각 기기 브라우저에만 저장

## 사용

- 공유 링크로 열기: `https://<계정>.github.io/homestead-calendar/#api=<웹앱URL>&key=<접근키>`
  → 열면 기기에 저장되고 주소창에서 자동으로 지워짐
- 데모: `?demo`

## 화면

- 오늘 카드: 청소(오늘 퇴실) · 연박(출입금지) · 오늘 입실 완료 · 오늘 밤 빈방
- 타임라인: 객실 8줄 × 14일, 바 = 실제 입실, 🧹 = 퇴실(청소)
